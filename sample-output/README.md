# Sanitized Sample Output



This directory is reserved for sanitized cluster-validation examples.



Acceptable future examples include:



\- Static-validation results

\- Read-only audit summaries

\- Quorum status

\- Resource status

\- Constraint validation

\- Controlled failover observations

\- Approved fencing-test summaries

\- Rollback validation



Before adding output, remove or replace:



\- Company and customer names

\- Real hostnames, domains and IP addresses

\- Usernames and email addresses

\- Credentials, tokens and keys

\- Fence-device parameters

\- Internal application names

\- Sensitive paths

\- Infrastructure identifiers

\- CIB content



Use only reserved documentation ranges:



\- `192.0.2.0/24`

\- `198.51.100.0/24`

\- `203.0.113.0/24`



Samples are illustrative and must not be presented as evidence of production deployment, compliance, successful live fencing or end-to-end availability.
